MODULE 1.3

🧱 WAT in practice

This module organizes the minimal architecture of an agentic system by separating workflow, agent and tools. The objective is to avoid a monolithic solution that is difficult to explain, measure and operate.

1

🗺️ Workflow as the backbone

Workflow is the layer that defines order, checkpoints and transitions. It takes the structural logic out of the agent's improvisation.

Main concept

Good workflow makes it clear what goes into each phase, what comes out and under what conditions execution progresses.

Practical tip

If you can't draw the phases on a sheet of paper, you probably don't have a clear workflow yet.

2

🧠 Agent as decision layer

The agent enters to interpret context and choose the next best action within the system limits.

When to use

Contextual classification, source choice, local planning and prioritization with controlled ambiguity.

When to avoid

Persistence, fixed call, automatic sending without approval and scheme validation.

3

🛠️ Tools as concrete levers

Tools are the system's action points. The clearer, smaller and more auditable, the better the agent's predictability.

Technical criteria

A good tool does just one thing, has a clear schema and returns a standardized result.

Common mistake

Create a giant tool that mixes search, transformation, recording and notification at the same point.

4

🔀 Handoffs and composition

Mature systems grow by composition. Handoffs avoid excessive coupling and help share responsibility.

Main concept

Each handoff needs to make it clear what is being passed, in what format and what stage it takes from then on.

Alert

Vague handoff becomes black hole: responsibility changes, but no one knows what was transferred.

5

👀 Initial Observability

Without visibility, the system seems magical when it works and mysterious when it fails. Observability trades magic for engineering.

Register

Current phase, decision made, tool used, relevant input and output generated.

Avoid

Vague logs such as “an error occurred” or “workflow ended” without operational context.

6

🏗️ WAT map laboratory

The student closes the module by drawing the minimum architecture of a real case, separating workflow, agent and tools with clear responsibility.

Exercise

Choose a process and design the phases, agentic decision points and necessary tools.

Deliverable

One-page WAT map with flow, handoffs and observability points.

✓ Saw how handoffs and small tools help to scale the architecture.
